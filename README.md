# Student GPA Calculator

A simple GPA calculator designed to help students calculate their grade point average based on course credits and letter grades.

## Features

* Add multiple courses
* Enter course credits
* Select letter grades
* Automatically calculate GPA
* Credit-weighted GPA calculation
* Clean and responsive interface
* Works on desktop and mobile devices

## Grading Scale

The calculator uses a standard 4.0-style grading scale, including:

* A = 4.0
* A- = 3.7
* B+ = 3.3
* B = 3.0
* B- = 2.7
* C+ = 2.3
* C = 2.0
* C- = 1.7
* D = 1.0
* F = 0.0

## Technologies Used

* HTML
* CSS
* JavaScript

## Purpose

This project was created as a practical student productivity tool and as part of my web development learning portfolio.

## How to Use

1. Enter a course name.
2. Enter the number of credits.
3. Select the course grade.
4. Add additional courses if needed.
5. Calculate your GPA.
